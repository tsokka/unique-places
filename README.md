# unique.places

Учебный проект на Angular 22: каталог необычных мест со всего мира.

## Этап 1

- Верстка главной страницы по макету (1440 и 1920)
- Массив из 42 мест, вывод карточек через `@for`
- Условное отображение необязательных данных через `@if`

## Этап 2

- Переиспользуемый компонент `PlaceCard` с `input()` и `output()`
- Управление состоянием через `signal()` и `computed()`
- Фильтрация мест по категориям
- Избранное со счетчиком и сохранением в `localStorage`
- Модальное окно `PlaceDetails` с полной информацией о месте
- Собственные пайпы для категории, рейтинга и стоимости
- `TooltipDirective` для подсказок на кнопках избранного
- Необязательные бейджи и состояние пустого списка

## Структура

- `frontend` — Angular-приложение
- `backend` — учебный бэкенд курса, на этом этапе не используется

## Запуск

Нужен Node.js 22.22+ или 24.15+.

```bash
cd frontend
npm install
ng serve
```

Приложение откроется на http://localhost:4200

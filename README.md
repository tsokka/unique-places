# unique.places

Учебный проект на Angular 22: каталог необычных мест со всего мира.

## Этап 1

- Вёрстка главной страницы по макету (1440 и 1920)
- Массив из 42 мест, карточки выводятся через `@for`
- Необязательные поля (цена, рейтинг, теги) скрываются через `@if`
- Кнопка «Подробнее» / «Скрыть» раскрывает полное описание, каждая карточка независимо

## Структура

- `frontend` — Angular-приложение
- `backend` — учебный бэкенд курса, на этом этапе не используется

## Запуск

Нужен Node.js 22.22+ или 24.15+.

```bash
cd frontend
npm install
ng serve
```

Приложение откроется на http://localhost:4200

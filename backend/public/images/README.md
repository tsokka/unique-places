# Изображения мест

Поместите изображения мест в папку `public/images/places/`.

Например:

`public/images/places/mist-springs.jpg`

Тогда Backend раздаст файл по адресу:

`http://localhost:3000/images/places/mist-springs.jpg`

В данных места достаточно указать:

`imageUrl: '/images/places/mist-springs.jpg'`
